# Project Requirements Document (PRD)

## Project Overview
"BaseCamp" is a dual-sided mobile application designed to bridge the gap between volunteers and organizations in India. It replaces fragmented WhatsApp groups and word-of-mouth with a centralized, highly gamified, and visually bold platform built to resonate with the modern youth. 

## Target Audience
1. **Volunteers:** College students, working professionals, and tech-savvy individuals looking for meaningful ways to give back.
2. **Organizations:** NGOs, non-profits, and corporate CSR (Corporate Social Responsibility) teams seeking reliable volunteers.

## Core Problem to Solve
Lack of a centralized, reliable, and engaging platform for discovering volunteering opportunities in India. Existing solutions feel bureaucratic and dull.

## Key Features
*   **Dual-Role Onboarding:** Seamless, high-energy flow to register as either a Volunteer or an Organization.
*   **Event Discovery:** Location-based and cause-based (e.g., Environment, Education) event feed featuring bold, Neo-Brutalist event cards.
*   **Organization Dashboard:** Tools to create events, manage RSVPs, track attendance, and verify volunteer hours.
*   **Volunteer Profile (Gamified):** A dynamic resume of social good, tracking hours and displaying vibrant earned badges.
*   **In-App Notifications:** Real-time updates for event changes and upcoming shifts.

## Monetization Strategy
*   **Freemium for NGOs:** Basic event listings are free. Premium subscriptions allow for "Boosted" events.
*   **Corporate CSR Portal (B2B):** Paid enterprise accounts for companies to track ESG metrics.
*   **Verified Badges:** Small one-time fee for background-checked organizations.
